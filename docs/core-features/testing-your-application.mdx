## Overview

Preview Mode runs your project's development server from inside the task and shows the
result in an embedded browser, so you can check an agent's work before you merge it without
switching windows.

**What you get:**
- **Embedded viewing**: see your application running directly in Kablan
- **Dev Server Logs**: development server output at the bottom of the panel, expandable
- **No context switching**: start the server, look at the page, go back to the diff

## Setting Up Preview Mode

<Steps>

<Step title="Configure Development Server Script">
  Set the command that starts your development server in project settings under Dev Server Script —
  `npm run dev`, `pnpm dev`, `cargo run`, whatever your project uses.

  <Frame>
  <img src="/images/preview-mode-dev-script-config.png" alt="Configuring the dev server script in project settings" />
  </Frame>

  <Info>
  You may also need a setup script (e.g. `npm install`) to install dependencies before the
  development server starts. Configure this in project settings under Setup Scripts.
  </Info>

  <Tip>
  Ensure your development server prints the URL (e.g. `http://localhost:3000`) to stdout/stderr
  for automatic detection.
  </Tip>

</Step>

<Step title="Start Development Server">
  In the Preview section, click the **Start Dev Server** button to start your development server.

  <Frame>
  <img src="/images/preview-mode-start-dev-server.png" alt="Starting development server from task interface" />
  </Frame>

  Kablan will:
  - Launch your configured development script
  - Detect the URL of your website and load it
</Step>
</Steps>

## Using Preview Mode

### Accessing the Preview

Once your development server is running and a URL is detected:

1. **Click the Preview button** (eye icon) in the task interface
2. **View embedded application** in the iframe
3. **Interact with your app** directly within Kablan

<Frame>
<img src="/images/vk-preview-interface.png" alt="Preview mode showing embedded application with toolbar controls" />
</Frame>

### Preview Toolbar Controls

The preview toolbar provides essential controls for managing your preview experience:

<Frame>
<img src="/images/vk-preview-toolbar.png" alt="Preview toolbar showing refresh, copy URL, open in browser, and stop server controls" />
</Frame>

- **Refresh**: Reload the preview iframe
- **Copy URL**: Copy the development server URL to clipboard
- **Open in Browser**: Open the application in your default browser
- **Stop Dev Server**: Stop the running development server

### Dev Server Logs

At the bottom of the Preview panel, you'll find Dev Server Logs that can be expanded or collapsed.
These logs show real-time output from your development server, making it easy to monitor server
activity, errors, and debugging information without leaving the preview.

<Frame>
<img src="/images/vk-dev-server-logs.png" alt="Dev Server Logs showing expandable/collapsible log output at bottom of preview" />
</Frame>

## Troubleshooting

If the preview doesn't load automatically, ensure your development server prints the URL to
stdout/stderr for automatic detection.

Supported URL formats:
- `http://localhost:3000`
- `https://localhost:3000`
- `http://127.0.0.1:3000`
- `http://0.0.0.0:5173`

<Note>
URLs using `0.0.0.0` or `::` are automatically converted to `localhost` for embedding.
</Note>
