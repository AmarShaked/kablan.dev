## Creating Your Project
Click the **Create Project** button to choose from two options:
- **From existing git repository**: Browse your file system and select from a list of git repositories sorted by recent activity
- **Create blank project**: Generate a new git repository from scratch
Each project represents a git repository. After creation, you can configure it with setup scripts, dev server scripts, and other settings.


<Note>
A new project runs with no scripts at all. Configure them before your first task and the agent starts in a repository that already has its dependencies.
</Note>

## Repository Settings

Press `G` then `S` to open **Settings**, or open the command bar with `Cmd/Ctrl + K` and choose **Settings**. Select **Repositories** in the sidebar, then pick your repository from the dropdown.

<Frame>
<img src="/images/settings-beta-repositories.png" alt="The Repositories section of Kablan Settings, with the repository selector, general settings, and the scripts below them" />
</Frame>

Everything here is per-repository, and applies to every task that uses it. Changes save with the **Save Settings** button.

### General Settings

- **Display Name** — a friendly name for the repository.
- **Repository Path** — where it lives on disk.
- **Default Working Directory** — a subdirectory the agent runs in, for monorepos. Leave empty for the repository root.
- **Default Target Branch** — the base branch new worktrees branch off, and the branch pull requests target.

### Setup Script

Runs inside the worktree after it is created and before the coding agent starts. Use it to install dependencies or prepare the environment.

| Project | Command |
|---|---|
| Node.js | `npm install` |
| Python | `pip install -r requirements.txt` |
| Rust | `cargo fetch` |
| Several steps | `npm install && npm run build:deps` |

<Note>
Each task runs in its own [git worktree](https://git-scm.com/docs/git-worktree), which is a fresh checkout — it will not have your `node_modules`, your build cache, or your `.env`.
</Note>

**Run setup script in parallel with coding agent** starts the agent without waiting for setup to finish. Useful when installs are slow and the agent spends its first minute reading code anyway.

### Dev Server Script

Starts a development server for the repository, from the **Start Dev Server** button in the [Preview](/core-features/testing-your-application) section.

| Framework | Command |
|---|---|
| Vite | `npm run dev` |
| Next.js | `npm run dev` |
| Create React App | `npm start` |
| Django | `python manage.py runserver` |
| Rails | `rails server` |

### Cleanup Script

Runs inside the worktree after the coding agent finishes, and only if it changed something. Treat it like a pre-commit hook — formatters, linters, tests.

| Language or tool | Command |
|---|---|
| Prettier | `npx prettier --write .` |
| ESLint | `npx eslint --fix .` |
| Rust | `cargo fmt` |
| Black | `black .` |
| Ruff | `ruff check --fix .` |
| Go | `go fmt ./...` |

### Archive Script

Runs when the workspace is archived. Use it to stop services the task started or release resources — `docker compose down`, `pg_ctl stop`, killing a process still holding a port.

<Warning>
Make archive and cleanup scripts safe to run when there is nothing to clean up. Append `|| true` to commands that fail when the resource is already gone.
</Warning>

### Copy Files

Comma-separated list of files to copy from the original repository directory into the worktree, after it is created and before the setup script runs. Glob patterns work. Useful for environment-specific files like `.env` and local config.

<Warning>
Make sure these files are gitignored or they could get committed!
</Warning>
