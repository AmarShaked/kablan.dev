Settings are application-wide and apply to every project.

## Opening Settings

Press `G` then `S`, or open the command bar with `Cmd/Ctrl + K` and choose **Settings**. You can also click the ⚙️ icon in the top bar.

<Frame>
<img src="/images/settings-beta-general.png" alt="The Kablan Settings dialog open on the General section, showing Appearance, Theme, Language, and Editor options" />
</Frame>

Settings open as a dialog over your current view, so you do not lose your place. Changes are saved with the **Save Settings** button; the dialog warns you if you try to close it with unsaved changes.

<Note>
In v0.11.6 the sidebar also lists **Organization Settings** and **Remote Projects**. Those belong to a hosted backend that `npx kablan` does not ship, and they report that a remote client is not configured. Nothing on this page depends on them, and they are hidden from the next release on.
</Note>

## Appearance

- **Theme** — Light or Dark.
- **Language** — Browser Default follows your system language.
- **Time** — 12-hour or 24-hour timestamps.

## Default Coding Agent

Choose the agent and variant pre-selected when you create a new task attempt or follow-up.

1. **Default Agent Configuration** — e.g. Claude Code, Codex, Gemini CLI.
2. **Variant** — e.g. Default, Plan, Router, where the agent offers them.

<Tip>
This is only a default. You can override the agent and variant per attempt in the create attempt dialog.
</Tip>

## Editor

### Editor Type

Choose the editor Kablan opens your worktree in:

- **VS Code**, **Cursor**, **Windsurf** — VS Code and its forks
- **Zed**, **Neovim**, **Emacs**, **Sublime Text**
- **Antigravity**
- **Custom** — any shell command

### Custom Editor Command

With **Custom** selected, give a shell command. It receives the file or directory path as an argument.

```bash
# Open with IntelliJ IDEA
idea

# Open with Sublime Text at an explicit path
/Applications/Sublime\ Text.app/Contents/SharedSupport/bin/subl

# Open with your own script
~/scripts/open-editor.sh
```

### Remote SSH

If Kablan runs on a different machine from your browser — a VPS, or a box you reach through a tunnel — Kablan can mint a `vscode-remote` URL so your local editor opens the remote checkout over SSH instead of assuming localhost.

<Frame>
<img src="/images/settings-beta-editor.png" alt="Editor settings showing the Editor Type dropdown and the Remote SSH Host field" />
</Frame>

Available for **VS Code**, **Cursor**, and **Windsurf**.

- **Remote SSH Host** (optional) — hostname or IP, e.g. `example.com`, `192.168.1.100`, `my-server`.
- **Remote SSH User** (optional) — falls back to your SSH config or default user.

Leave the host empty and Kablan spawns a local command as usual.

With a host set, **Open in Editor** generates a URL like `vscode://vscode-remote/ssh-remote+user@host/path/to/project`, which your local editor opens and connects over SSH. This works for both the project and an individual task worktree.

Before you rely on it, check that `ssh user@host` connects without prompting for a password, and that you have the Remote-SSH extension installed in your editor.

## Git

### Branch Prefix

Kablan creates a git branch for every task. This sets the prefix on the generated name.

| Prefix | Resulting branch |
|--------|------------------|
| `vk` | `vk/1a2b-implement-auth` |
| `feature` | `feature/1a2b-implement-auth` |
| *(empty)* | `1a2b-implement-auth` |

<Tip>
Match whatever your repo already uses, so Kablan's branches sort alongside your own.
</Tip>

### Workspace Directory

Where Kablan keeps the per-task git worktrees. They are created in a `.kablan-workspaces` subdirectory of this path.

Leave it empty for the system default. Set it if you want worktrees on a different disk.

<Warning>
Changing this needs an app restart, and existing worktrees stay where they are.
</Warning>

## Pull Requests

Configure what happens when Kablan opens a PR for a task branch.

- **Auto-generate PR description by default** — have the agent draft the description rather than opening with an empty body.
- **Custom prompt** — supply your own prompt for that draft, if the default does not match how your team writes PRs.

## Commits

Configure commit behaviour on task branches.

- **Commit reminder** — prompt you when a task has finished with changes left uncommitted.
- **Custom prompt** — supply your own prompt for generated commit messages.

## Notifications

Useful when you have several agents running and are not watching the tab.

- **Sound Notifications** — audio when a task finishes, needs attention, or errors. You can preview the sound from the settings row.
- **Push Notifications** — browser notifications when Kablan is not in focus. Your browser asks permission the first time you enable this.

## Message Input

Choose whether `Enter` or `Cmd/Ctrl + Enter` sends a message in the chat input, and which one inserts a newline.
