One cockpit, every agent

Run agents like you run infra

Kablan.dev turns a folder of repos into a control room — a coding agent per branch, supervised and reviewable.

🏗️

An agent on every branch

Start a session on any branch and Kablan spins a Claude Code agent in its own git worktree — isolated, auto-managed, and yours to resume anytime.

🛡️

Supervise every action

Approve or deny each tool call inline — or set a session to bypass. Read-only tools (Read, Grep, Glob) run un-gated so you only weigh in on what matters.

💬

A real coding chat

Full markdown, syntax-highlighted diffs for every edit, live todo checklists, plan cards, and collapsible thinking — not a wall of raw stream output.

⌨️

A composer that keeps up

Paste or drop images, @-mention files, fire / commands, pick the model & thinking level, and queue follow-ups while the agent works.

⏪

Rewind & retry

Edit an earlier message to fork the session and re-run from there. Every branch's chat is persisted to disk with a retention you control.

▶️

Per-branch dev servers

Run a dev server for any worktree with live logs. Another branch holding the port? One click to replace it and take over.

🔀

Git & integrations, in-app

Branches, worktrees, working diffs and pull — plus a GitLab & Linear tab that only shows up when you've connected them.

🔑

Your subscription, no API key

Kablan drives your installed claude CLI, so agents run on your Claude Pro/Max login — not pay-as-you-go API billing.

⚡

Native & fast

A Rust core (Axum) in a Tauri shell does the git, process and agent work. Small footprint, instant startup, light or dark.

On your terms

Runs on your Claude subscription

Most agent tools quietly put you on metered API billing. Kablan drives the real Claude Code CLI, so it uses the Pro/Max login you already have — and when a tool needs permission, you decide.

How it works

Point it at your code and go

A Rust core drives real git, your dev scripts, and the Claude Code CLI; a React UI renders it. Shipped as one native app.

1

Pick your projects folder

Kablan scans for git repos and builds your project list — features, branches and worktrees — in seconds.

2

Start a session on a branch

An agent spins up in a fresh worktree, node_modules and .env seeded, ready for your first message.

3

Supervise & stay in flow

Watch it work, approve the risky tools, review the diffs, run the dev server — never touching a terminal tab.
