Everything, one window

Stop juggling terminals

Kablan.dev pulls your whole local workflow into a single, fast surface.

🗂️

Every repo at a glance

Recursively discovers all git repos under a folder you pick. Nested repos like acme/frontend/app stay grouped and instantly searchable.

🌿

Branches & worktrees

One unified, virtualized list — current branch, ahead/behind vs. upstream, and a commit-activity heatmap scoped to each branch's own work.

▶️

Dev servers, one click

Start or stop a dev server from any row. One per project — starting a new one replaces the old — with live console logs streamed in.

🔑

Environment editor

View and edit each project's and each worktree's .env files right in the app. No more cd-ing around to find them.

🔀

Git without the terminal

Check out branches and pull — including fast-forwarding branches that aren't even checked out — without dropping to a shell.

⚡

Native & fast

A Rust backend (Axum) in a Tauri shell. Small footprint, instant startup, and a warm, focused UI in light or dark.

Under the hood

Native where it counts

A Rust core does the git, filesystem and process work; a React UI renders it. Shipped as one Tauri app.
